How it works URL / QR → local parser → diagnostics

QR images are decoded in your browser with jsQR. Both the browser and CLI use the same deterministic parser. We check URL structure, address encoding and amount formatting. We do not verify recipient identity, token decimals, payment status or transaction safety.

The baseline Solana Pay specification defines the supported fields. Unknown extensions need review. Solana Pay URLs do not encode a network.
